Tone is a Mac MP3 player designed for customizability without the clutter.

Features:
- Clean, simple navigation
- Maximum customizability
- Decluttered layout
- Compatibility with MacOS

What Makes It Different From Other mp3 Players:
- Keyboard Shortcut Allows Simple Play
- Customizable EQ In Settings
- Themes, Accent Colors, And Layouts That Make Listening An Amazing Experience

Installation:
1. Go to the Releases page (Or Click On 'Code' At The Very Top Of This Page) and download the Tone.zip file
2. Double click on the .zip file to unzip it
3. Drag Tone.app into your Applications folder

**Note for first-time launch:** If macOS says the app cannot be opened because it is from an unidentified developer, right-click (or Control-click) **Tone.app**, select **Open**, and click **Open** again in the pop-up dialog.
